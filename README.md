# Clippy Codex Pet

This repo contains the sprites and everything needed for Clippy, the famous assistant from Windows back in the '90s, using the new Codex pets ability.

## Preview

![Clippy image placeholder](image.png)

## Setup

1. Clone this repo.
2. Copy the `Clippy` folder into the `pets` folder inside your own `.codex` directory.

For example, on my machine that path is:

```text
/Users/diegocabezas2/.codex/pets/Clippy
```

3. Select the pet in Codex:

```text
Codex -> Settings -> Appearance -> Pets
```

4. In Codex, type `/pet` to bring Clippy to life.
5. Type `/pet` again to hide Clippy.
